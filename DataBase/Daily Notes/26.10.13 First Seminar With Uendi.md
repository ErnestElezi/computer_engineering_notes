## Problemi I
> [!Todo] Shtëpia Botuese
> Një shtëpi botuese boton libra të llojeve të ndryshme si libra artistikë ashtu edhe shkencorë.
Libri karakterizohet nga titulli, ISBN-ja, viti i publikimit, kategoria, dhe lista e autorëve
(mund të jenë një ose më shumë autorë).
Çdo libër ka një editor të përzgjedhur nga kompania për kontrollin e publikimit. Editori
karakterizohet nga emri, mbiemri dhe datëlindja. Libri editohet nga vetëm një editor, dhe
për çdo libër ruhet data e fillimit dhe mbarimit të procesit të editimit.
Pas shtypjes së librit, shtëpia botuese furnizon librari të ndryshme me librat e porositur. Çdo
librari karakterizohet me emrin e librarisë, adresën fizike, emrin dhe mbiemrin e një personi
përgjegjës, numrin e telefonit dhe adresën elektronike. Për çdo librari dhe libër, ruhet edhe
sasia e librave të dorëzuar.

### Identify the entities
Entities are things that carry properties/attributes
1. *Book* ( Title , ISBN , Release_Year , Category ) __# We don't include authors cause that would be a Multi-Valued Attribute__
2. *Editor* ( Name , Surname , Birth_Date )
3. *Librari* ( Name , Physical_Address , Representative_Name , Representative_Surname , Phone_Number , Email ) __# The physical address is a Compound Attribute made form a Postal Code and Street Name__
4. *Author* ( Name , Surname ) __# We must add this entity to avoid storing multi valued attributes on the Book entity__

### Identify the relationships
Relations and Relationships are not the same thing __( Be careful )__
1. Edited\_By _( Books are edited by Editors )_ ( Start_Date , End_Date ) __# We have to store the start and end date on the relationship because only it is unique to one edit. A Book can be edited multiple times and a Editor can edit multiple books__
2. Supplied _( Books are supplied to Libraries )_ ( Amount )
3. Authored\_By _( Books are authored by Authors )_

### Identify the types of relationships
1. Edited\_By _# A book can be edited by one Editor but an Editor can edit many books_ __( Many or Zero to One )__
2. Supplied __( Many or Zero to One )__
3. Authored\_By __( Many to Many )__

### Identify the entities
1. *Publishing_House* ( Name )
2. *Book* ( Title , <u>ISBN</u> , Release_Year , Category ) 
3. *Copy* ( <u>ID</u> , Description )
4. *Person* ( Name , Surname , Birth_Date , ID , Phone_Number , Email , Postal_Address )


### Identify the relationships
1. Publish _( Publishing Houses publish Books )_
2. Has\_Copy _( Books have copies )_
3. Borrow _( Persons borrow Copies )_ ( Date , Time )
4. Request _( Persons request Books )_ ( Date )
5. Return _( Persons return Books )_ ( Date , Description )

### Identify the types of relationships
1. Publish __( One to Many)__ _# Publishing Houses publish many Books / A Book is only published by one House_
2. Has\_Copy __( One to One or Many)__ _# One Book can have many Copies (or none) / A Copy only belongs to one Book_
3. Borrow __( One to One )__ _# One Person can borrow one Copy / A copy can only be borrowed by one Person_
4. Request __( Many to One )__ _# Many Persons can request one Book_
5. Return __( One to One )__ _# One Copy can only be returned by one Person_
