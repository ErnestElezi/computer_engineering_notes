# Relational Database
A way to organise data which forces constraints on the data to be properly formatted. Where data is linked together by other data dependent on it or that it depends on.

E.g. Students follow courses ( so they have a relation to the course )
Courses also have many students ( so the relationship goes both ways )
In this case the data is independent because we can have one without the other.

E.g 2: A classrooms have certain facilities inside them ( PCs, Laptops, SmartBoards, Equipment ). These facilities can only be in one classroom at a time. In this case the data is again related but this time not independent.
If we wish to delete a classroom we must also delete the facilities inside it first
